# 第一章-面向对象基础
## 1.面向对象和面向过程
+ 编程思想

:::info
就是人们利用计算机来解决问题的思维

:::

+ 分类
    - 面向过程

:::info
它是一种编程思想，强调的是以步骤为基础完成各种操作

:::

    - 面向对象

:::info
它是一种编程思想。强调的是以**对象**为基础完成各种操作，它是基于面向过程的，说到面向对象，不得不提的就是它的三大思想特点：

1.更符合人们的思考习惯

2.把复杂的事情简单化

3.把人们（程序员）从执行者变成指挥者

总结：万物皆对象

:::

# 第二章-闭包和装饰器
## 1.闭包
+ 概述：

:::color4
在内部函数中访问了外部函数的变量 这种写法就叫闭包

:::

+ 作用：

:::color4
延长外部函数的变量的生命周期

正常情况下，函数执行完毕，变量就消失了

有了闭包，即使外部函数执行完毕后，内部函数依旧可以使用外部函数的变量

:::

+ 前提：

:::color4
1.有嵌套

2.有引用

3.有返回

:::

## 2.装饰器
+ 概述：

:::color4
闭包的一种写法，本质就是：闭包函数

:::

+ 作用：

:::color4
在不改变原有函数代码基础上，对其功能做增强

:::

+ 前提：

:::color4
1.有嵌套

2.有引用

3.有返回

4.有额外功能

:::

+ 用法：

:::color4
传统写法：装饰后的函数名 = 装饰器名（原函数名）

语法糖：在原函数的基础上在加一个@装饰器名

:::

## 3.深浅拷贝
+ 所谓的深浅拷贝分布指的是：

:::color4
浅拷贝：copy模块的copy()

深拷贝：copy模块的deepcopy()函数

:::

+ 大白话解释深浅拷贝：

:::color4
深拷贝拷贝的多，浅拷贝拷贝的少

**<font style="color:#DF2A3F;">深拷贝：创建新的对象，嵌套的对象也创建新的对象。</font>**<font style="color:#DF2A3F;">  
</font>**<font style="color:#DF2A3F;">浅拷贝：只创建新的外层对象，里面嵌套的可变对象仍然引用原来的对象。</font>**

:::

+ 对于可变类型和不可变类型

:::color4
深浅拷贝主要是针对可变类型来讲的，深拷贝拷贝所有层（可变），浅拷贝只拷贝外层（不拷贝嵌套的）；如果是针对不可编码类型，则用法和 普通赋值一样，地址不变

:::

# 第三章-网编和多线程
## 1.网络编程
:::color4
概述：就是用来实现网络互联的 不同计算机上 运行的程序间 可以进行数据交互

:::

## 2.IP地址
:::color4
<font style="color:#000000;">概述</font>：这是网络环境下每一台计算机的唯一标识，通过IP地址来找到指定的计算机

分类：IPv4和IPv6

IPv4：是目前大家使用的IP地址

IPv6：作为了解，IPv6是未来使用的IP地址

如何查看ip地址:

windows: ipconfig

linux,mac: ifconfig

测试网络连接：

ping 域名或者IP地址

作用：通过IP地址找到网络中唯一一台设备

:::

## 3.端口
:::color4
概述：用于标识进程的逻辑地址，通过端口来找到指定的进程

范围：0~66535，其中0~1023以及被系统占用或者用做保留端口，自定义端口时尽量避免这些范围

:::

## 4.协议
:::color4
概述：定义通信规则，符合协议则可以通信，否则无法正常通信

常用协议：TCP（用的最多）和UDP

TCP特点：

1.面向有连接

2.采用字节流传输数据，理论无大小限制

3.安全（可靠）协议

4.效率相对较低

5.区分客户端和服务器端

:::

##  5.并行与并发
:::color4
**1**.什么是多任务执行？

多任务是指在同一时间内执行多个任务

**2**.多任务执行的优势是什么？

多任务执行能够充分利用cpu资源，提高程序执行效率

**3**.多任务执行有哪两种表现形式

并发：在一段时间内交替去执行多个任务

并行：在一段时间内真正的同时一起执行多个任务

:::

## 6.进程
:::color4
概念：进程(Process)是cpu资源分配的最小单位，**<font style="color:#DF2A3F;">它是操作系统进行资源分配和调度运行的基本单位</font>**。

通俗理解：一个正在运行的程序就是一个进程，例如：正在运行的qq，微信等他们都是一个进程。

:::

## 7.线程
:::color4
概念：进程是分配资源的基本单位，一旦创建一个进程就会分配一定的资源，线程是cpu调度的基本单位，每个进程至少都有一个线程，而这个线程就是我们通常说的主线程

:::

# 第四章-生成器和正则表达式
## 1.迭代器
:::color4
概述：迭代器是python中的一种对象，用于在数据集合中逐个访问元素，而不需要暴露数据集合的底层实现。它提供了一种遍历集合元素的标准方式，适用于任何支持迭代的数据结构，如列表，元组等，range（）就是一个迭代器。 

:::

## 2.生成器
:::color4
概述：生成器就是一种特殊的迭代器，通过 `yield` 实现“每次只产生一个数据，用一个取一个”，从而节省内存。

:::

## 3.生成器和迭代器的区别
:::color4
1.实现方式  
迭代器：需要实现__iter__()和__next__()方法，手动管理迭代状态

生成器：通过yield关键字简化实现，自动管理迭代状态

2.代码复杂度

迭代器：通常需要更多的代码来管理状态和迭代逻辑

生成器：代码更简洁，更容易理解和维护

3.性能与内存

迭代器：性能和内存使用取决于实现，通常也是惰性计算

生成器：由于使用了yield，内存使用和性能优化自动管理，适合处理大数据或流数

4.使用场景

迭代器：适合需要对迭代过程进行高度控制，或者需要自定义复杂的迭代逻辑时使用

生成器：适合需要简洁地生成序列数据，尤其是在处理大数据或需要按需生成数据时，能够节省内存和提高性能

:::
